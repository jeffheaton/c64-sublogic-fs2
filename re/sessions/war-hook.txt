# The $FD00 hook in Europe 1917. R sets $08D7 (in every mode); in war mode the main loop's flip
# pass then shifts the $08D7 request out and calls $FD00 ($20BB-$20C0). $FD00-$FFF1 is zero in
# this image, so the CPU runs a chain of break interrupts ($FD00, $FD02, ... $FFF0): each goes
# through the IRQ vector $FFFE to the raster IRQ handler $2285 (counting jiffies) and returns two
# bytes on. At $FFF2 the residue bytes read as a call to $20D5 (the draw sequence); the main loop
# carries on with the two return addresses (4 bytes) left on the stack. Each R in war mode thus
# leaks 4 stack bytes and adds roughly 180 jiffies ($34), which the next integrator pass sees as dt.
# Peeks show SP at the top of the main loop ($204B) and the jiffy counter $34.
